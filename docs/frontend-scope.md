# Интерфейс MVP «Мост»

## Границы работы

Фронтенд: экраны, адаптивная вёрстка, навигация, формы, клиентская валидация,
состояния загрузки/ошибки/пустого списка, демонстрационные данные и подключение API.
Тиммейты реализуют бизнес-логику, хранение данных и интеграцию.
Демонстрационные значения рейтинга и баллов не считаются реальными расчётами.

## Обязательные экраны

1. Каталог Explore Tasks. Поиск, фильтры, Match, готовность, сортировки, закладки, Load More; параметры в URL.
2. Черновик. Краткое описание потребности и кнопка «Analyze with AI».
3. Уточнение. Не менее трёх уместных вопросов от системы, поля ответов,
   возможность вернуться к черновику без потери введённых данных.
4. Проверка карточки. Редактируемые поля: проблема, ожидаемый результат,
   критерии успеха, доступные данные, ограничения и сроки.
   Панель рейтинга с разбивкой и подсказками; подтверждение перед публикацией.
5. Страница задачи. Полное описание, рейтинг, сроки, статус и форма предложения команды.
6. Кабинет бизнеса. Свои задачи, предложения команд, сравнение подходов,
   сроков и состава. Выбор одной или нескольких команд либо завершение без выбора.
7. Кабинет команды. Свои предложения, статусы, выбранные проекты, этапы и баллы.
8. Прогресс. Команда отправляет результат этапа со ссылкой и описанием.
   Бизнес подтверждает результат или возвращает на доработку.
   Баллы отображаются после подтверждения сервером.

## Основной маршрут демонстрации

Бизнес → черновик → вопросы → редактирование и подтверждение карточки → каталог.
Команда → задача → предложение.
Бизнес → сравнение предложений → выбор команд.
Команда → результат этапа.
Бизнес → подтверждение этапа.
Команда → обновлённые баллы.

## Состояния интерфейса

- Каталог пуст, поиск ничего не нашёл, каталог загружается, ошибка загрузки.
- Пустой черновик, генерация вопросов, ошибка генерации, неполные ответы.
- Сохранение карточки, расчёт рейтинга, публикация, ошибка публикации.
- Предложение отправляется, отправлено, ошибка; новые варианты можно отправлять без лимита.
- Нет предложений, предложения получены, команда выбрана, отказ от выбора.
- Этап в работе, ожидает подтверждения, возвращён на доработку, подтверждён.

## Договорённости для интеграции

- Идентификаторы задач, команд, предложений и этапов приходят с сервера.
- Вопросы и рейтинг получает фронтенд через отдельный адаптер API.
- Для рейтинга нужны: итог 0–100, критерии с начисленными/максимальными баллами,
  список недостающих сведений и подсказок.
- Каталог получает опубликованные карточки, упорядоченные по убыванию рейтинга.
- Выбор команд передаётся массивом идентификаторов; пустой массив допустим
  при явном решении бизнеса не выбирать ни одной команды.
- Баллы и подтверждение этапов контролирует сервер; повторное подтверждение
  не должно начислять баллы повторно.
- В демо переключатель ролей служит только показу экранов; авторизация и права
  доступа обеспечиваются сервером при интеграции.
- Секреты и ключи внешних сервисов нельзя помещать во фронтенд.

## Приоритет при дедлайне 5 часов

Сначала сквозной сценарий всех восьми шагов и мобильная вёрстка.
Затем подключение реальных данных совместно с тиммейтами и проверка демонстрации.
Дополнительные профили, чат, уведомления и сложная аналитика вне первой версии.

## После объединения с сервером команды

Интерфейс находится в public/. Основная страница использует api-client.js;
автономная демонстрация сохранена отдельно в demo.html.
Поля, API и текущие ограничения описаны в api-contract.md.
Подключены исходный серверный рейтинг, JSON-хранилище, задачи и предложения;
для полного сквозного показа добавлены маршруты выбора команд и подтверждения этапов.

## AI Task Generator + AI Interview

Конструктор расширен без смены HTML/CSS/JavaScript и hash routing.
`ai-components.js` содержит общие фрагменты и преобразования карточки,
`ai-flow.js` — управление описанием, интервью и редактором, `demo-ai.js` —
отдельную явно обозначенную демонстрацию без LLM.

Интервью передаёт весь контекст серверному OpenAI-адаптеру после каждого ответа.
Редактор поддерживает требования, теги навыков, сложность, срок и размер команды,
улучшение, повторную генерацию и отмену последнего AI-изменения.
История и неотправленный ответ сохраняются вместе с черновиком.
Публикация доступна только после ручной проверки и подтверждения.

Настройка, контракт и сценарий проверки: [ai-task-generator.md](ai-task-generator.md).
