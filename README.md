# Мост — задачи бизнеса и решения студенческих команд

MVP на обычном HTML/CSS/JavaScript и Node.js, без внешних зависимостей. Бизнес описывает проблему, проходит минимум три уточнения, проверяет карточку и публикует её. Команды предлагают решения; бизнес вручную выбирает одну, несколько или ни одной команды. Баллы выдаются за подтверждённые этапы.

## Запуск

Нужен Node.js 22.9 или новее. Выполните `npm start`, откройте http://localhost:3000. Устанавливать пакеты не требуется. Для OpenAI скопируйте `.env.example` в `.env` и заполните `OPENAI_API_KEY` на сервере. После изменения настроек перезапустите сервер.

- `/` — общий каталог. Для действий создайте аккаунт бизнеса или команды. Роль фиксируется при регистрации; права проверяет сервер.
- `/demo.html` — отдельная демонстрация с переключением ролей и локальными данными.
- `/case.html` — готовый сценарий защиты с новой копией учебного кейса и двумя предложениями.
- `/prototype.html?variant=grid` и `?variant=list` — работающий учебный прототип записи с сохранением и отменой. Реальные услуги не бронируются.

Без ключа конструктор использует явно помеченное шаблонное уточнение. Проверка качества OpenAI доступна только при настроенном ключе; ошибка провайдера не подменяется успешной AI-генерацией.

## Что реализовано

- Единый рейтинг полноты 0–100 в редакторе, опубликованной карточке и каталоге. Расшифровка и недостающие сведения; мгновенный пересчёт общим алгоритмом.
- AI задаёт минимум три уместных вопроса; карточка редактируется и публикуется после ручного подтверждения. Проверка качества AI запускается отдельно и не меняет рейтинг.
- Общий каталог сортируется по готовности. Персональные рекомендации, поиск, фильтры по теме и готовности, дополнительные условия, закладки и пагинация.
- Профиль команды со списком участников, ролями, общими навыками и опытом. Снимок профиля и соответствия прикладывается к отклику.
- Неограниченные отклики: идея, план, срок, ссылка на прототип. Бизнес сравнивает и вручную подтверждает выбор.
- Два или три редактируемых этапа с критериями приёмки и общими 100 баллами. Команда согласует план; бизнес принимает результаты по очереди или возвращает на доработку.
- Аккаунты, salted scrypt пароли, HttpOnly-сессии, серверные проверки владельца задачи и команды.

## Проверка

`npm test` — сценарии API, адаптеров, интервью, рейтинга, каталога, прав, команды и этапов. `npm run lint` — синтаксис всего JavaScript и скриптов в HTML. AI-тесты используют тестовые ответы OpenAI; реальный ключ проверяется отдельным прогоном. Визуальная проверка браузером в среде агента недоступна.

Основное хранилище — `data/db.json`, либо `DATA_FILE` из окружения. Существующие задачи, отклики и старые этапы сохраняются. Старые записи без владельца не присваиваются новому аккаунту. Для полного управляемого показа создайте задачу после входа или используйте отдельное демо.

Сервер рассчитан на один процесс. После перезапуска потребуется снова войти; аккаунты и проектные данные сохранятся. Восстановление пароля, приглашения участников и OAuth пока не реализованы.
