# Мост — бизнес-задачи и студенческие команды

Хакатонный проект команды Aliskander. Новый интерфейс объединён с Node.js-сервером
из общей ветки: реальные задачи, отклики, решения бизнеса и этапы сохраняются в JSON-файле.

## Запуск

Нужен **Node.js 22+**. Внешние зависимости и установка пакетов не требуются.

```sh
npm start
```

Откройте **http://localhost:3000**. Сервер слушает только локальный интерфейс.
Переменные `PORT` и `DATA_FILE` позволяют изменить порт и путь к файлу данных.
По умолчанию данные сохраняются в `data/db.json`; эта папка исключена из Git.

Отдельное автономное демо с вымышленными задачами доступно на **http://localhost:3000/demo.html**.
Его данные хранятся только в браузере и не попадают в серверный каталог.
Для демонстрации без Node можно открыть `public/demo.html` двойным щелчком.
Основной `public/index.html` нужно открывать через сервер.

## Что объединено

- Существующие `src/rating.js`, API задач и предложений, JSON-хранилище и исходные тесты команды сохранены.
- Интерфейс перенесён в `public/`: каталог, поиск, фильтры, кабинеты, создание задачи по шагам.
- `public/api-client.js` переводит поля интерфейса в существующие поля сервера:
  `problem → context`, `outcome → expectedResult`, `success → successCriteria`.
- Сохраняются дополнительные сведения: компания, направление, срок, состав и контакт команды.
- Рейтинг рассчитывается на сервере по исходной шкале команды. Во фронтенде веса не дублируются.
- Живой предпросмотр, подсказки рейтинга, автосохранение и сравнение команд подключены к API.
- Добавлены пакетное подтверждение выбора команд и этапы с отправкой результата,
  доработкой и однократным подтверждением. Данные переживают перезапуск сервера.
- Старые JSON-файлы без `stages` поддерживаются без удаления задач и предложений.

## Показ за 3 минуты

1. В роли «Бизнес» создайте задачу, ответьте на вопросы и проверьте карточку.
2. Дополните критерии рейтинга, подтвердите публикацию.
3. На странице задачи выберите роль «Команда» и отправьте предложение с идеей и планом.
4. Вернитесь в роль «Бизнес» → «Мой кабинет» → сравнение предложений.
5. Выберите Orbit и подтвердите решение.
6. В роли «Команда» откройте «Прогресс проектов» и отправьте описание и ссылку на результат.
7. В роли «Бизнес» подтвердите этап либо верните его на доработку с комментарием.
8. После подтверждения в кабинете команды отображаются 100 баллов.

Для быстрого сравнения двух готовых предложений используйте отдельную страницу `/demo.html`.

## Структура

| Путь | Назначение |
|---|---|
| `public/index.html`, `public/styles.css`, `public/app.js` | Общий интерфейс, без сборки |
| `public/api-client.js` | Адаптер настоящего HTTP API |
| `public/draft-autosave.js` | Очередь автосохранения с защитой от устаревших запросов |
| `public/demo.html`, `public/demo-api.js` | Изолированная демонстрация без сервера |
| `src/server.js` | HTTP-маршруты и раздача статических файлов |
| `src/store.js` | Хранение задач, предложений и этапов |
| `src/rating.js` | Исходные критерии и уровни рейтинга команды |
| `src/presentation.js` | Разбивка серверного рейтинга и шаблонные вопросы |
| `test/mvp.test.js` | Исходные тесты команды |
| `test/integration.test.js` | Интеграция интерфейса с API и автосохранение |

## Проверка

```sh
npm test
npm run lint
```

Проверены исходные сценарии сервера и новый адаптер интерфейса через реальный HTTP:
сохранение и восстановление черновика, неизменность шкалы рейтинга, публикация,
идея/план/ссылка предложения, выбор одной/нескольких/ни одной команды,
доработка, подтверждение этапа, сохранение после перезапуска и защита от повторного начисления.

Визуальная проверка в браузере в среде агента недоступна; перед выступлением
проверьте сценарий в обычном браузере и в узком окне.

## Ограничения MVP

- Как и в исходном сервере, полноценной авторизации нет: бизнес использует общий кабинет,
  а переключение ролей служит демонстрации. Orbit — фиксированная демонстрационная команда.
  Не публикуйте сервер с реальными закрытыми данными до добавления авторизации и проверки прав.
- Уточняющие вопросы формируются из незаполненных полей по шаблонам; это не подключение LLM.
- Хранилище рассчитано на один процесс сервера; чат, уведомления и совместное редактирование отсутствуют.
- В этой версии выбранной команде создаётся один этап «Демонстрация рабочего прототипа» на 100 баллов.

Подробности маршрутов и адаптера: [docs/api-contract.md](docs/api-contract.md).
